**Charivari @VERSION@** — rough music for one sound: one sample paraded as sixteen caricatured mummers (CLAP and VST3).

| System | Installer |
|---|---|
| macOS 10.15+ (Apple Silicon and Intel) | `Charivari-@VERSION@-macOS.pkg` |
| Windows 10 / 11, 64-bit | `Charivari-@VERSION@-Windows-x64-Setup.exe` |
| Linux x86_64 (WebKitGTK 4.1, GTK 3) | `Charivari-@VERSION@-Linux-x86_64.tar.gz` |

Each installer has its `.sha256`. The installers are not signed: see the README for the one-time step on macOS (Privacy & Security › Open Anyway) and Windows (SmartScreen › More info › Run anyway). The Windows and Linux installers are added here a few minutes after the release, when GitHub has built and checked them.

New in 1.0.1: with **Source: MTS-ESP**, a ZD scale can be laid on the master's notes, from the subject's tonic.
